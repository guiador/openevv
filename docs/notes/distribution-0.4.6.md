# Android and NVDA 0.4.6 / Android y NVDA 0.4.6

This experimental downstream distribution completes the existing English, Spanish, German, French and Italian interfaces in Android and NVDA, including accessible dictionary labels, errors, credits, experimental response controls, warnings, translated add-on metadata and installed help. Voice and settings identifiers remain compatible. It retains the engine safety corrections proposed separately in [upstream PR #55](https://github.com/Mudb0y/openevv/pull/55).

Download **Principal** for the usual Android installation. **Auxiliar** is an optional independent second installation. Both APKs contain ARM64, ARMv7 and x86_64 libraries, require Android 6/API 23 or later and preserve this distribution's existing debug signer. The original automatic updater is disabled. The NVDA add-on targets NVDA 2026.3 x64 (manifest range 2026.1–2026.3). Standalone Windows DLLs are supplied separately; they are not add-on installers. See [installation and build instructions](https://github.com/guiador/openevv/blob/main/docs/distributions.md).
