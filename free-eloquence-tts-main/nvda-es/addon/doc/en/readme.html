OpenEVV for NVDA 0.4.6

Installation and controls

Open the .nvda-addon file, install and restart NVDA. Select OpenEVV — extended speech with NVDA+Control+S. Select the language and voice in Speech; extended controls are in Settings → OpenEVV. The panel follows the selected voice language when opened.

Pauses and reading

Shorten all is enabled initially. Choose normal pauses, shorten at the end or shorten all. Explicit NVDA pauses have a separate percentage. Other controls include phrase prediction, digits/pairs/triplets, verification codes, five spelling modes, capitals, text cleanup, SSML and seven code-reading options.

Audio and files

64 language/voice combinations, eight output rates, five resampling modes, level enhancement and five-band equalizer. Left/center/right balance. Test saved settings or export stereo PCM16 WAV. Apply changes before testing. Export accepts up to 100,000 characters, uses an isolated engine and supports cancellation without overwriting the destination.

NVDA integration

Configure dictionaries, personal abbreviations, symbols and CLDR emoji descriptions in NVDA menus. Code and number preparation precedes symbol processing; NVDA character spelling is not duplicated. White noise and keeping audio awake use global NVDA settings, with choices up to 300 seconds. They do not prevent Windows sleep or guarantee zero latency.

Compatibility and validation

Intended for NVDA 2026.3 x64; manifest range 2026.1–2026.3. The real DLL, 64 voices, resampling, pauses and WAV output were tested. APIs and the panel were checked against official code and simulations. Not tested in a real NVDA 2026.3 session. Classic mode resamples from 11,025 Hz. Quality now offers experimental Wideband and Native 16 kHz base modes. Native mode selects 16 kHz output; higher outputs resample from this base. Restore defaults returns to classic mode without changing the voice or equalizer. Modes are stored per profile and apply to WAV export. Select another synthesizer or reinstall the previous edition to revert. No automatic updater.

Pronunciation dictionaries

Supports Eloquence Dictionary Manager sets, personal entries and .dic files in the openevv folder in your NVDA configuration. Changed files reload automatically while speaking. No managed set is selected by default.

Experimental response

Disabled by default. Apply or save before testing. Changes run between synthesis calls. Small pieces reduce discarded synthesis after cancellation, but may add pauses. WASAPI, the device and NVDA control playback buffering. Audible latency is not measured here.

Enable experiments

Disabling restores normal behavior and keeps values for another test.

Characters per piece

Lower: faster cancellation, possible gaps and less context. Higher: smoother speech, longer discard time. Without hard cuts, a long word can exceed the limit.

Split at sentence ends

On: uses natural pauses. Off: keeps more context, but waits for the character limit.

Samples per native block

Lower: earlier delivery and more callbacks/CPU. Higher: fewer callbacks, coarser delivery. Duration depends on sample rate.

Samples accumulated before feeding

Lower: more frequent delivery and gaps under load. Higher: more accumulation. Index marks force delivery; a block can overshoot the threshold. This does not set the WASAPI buffer.

Cut within words

May speed up discard, but breaks pronunciation, codes, combining emoji and prosody. Skipped for annotations, spelling or temporary pitch/rate/volume. Does not detect syllables.

Light output processing

Reduces gain calculation and soft limiting; keeps EQ and balance. May lower volume or distort clipped peaks.

Punctuation and symbol pronunciation (NVDA)

Uses the current NVDA profile setting, shared with other synthesizers. Apply or OK saves; Cancel discards. Customize individual symbols in NVDA’s Punctuation/symbol pronunciation dialog.
