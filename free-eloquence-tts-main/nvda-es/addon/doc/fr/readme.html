OpenEVV pour NVDA 0.4.4

Installation et réglages

Ouvrez le fichier .nvda-addon, installez et redémarrez NVDA. Sélectionnez OpenEVV Español — sonido ampliado avec NVDA+Contrôle+S. Choisissez la langue et la voix dans Parole ; les options supplémentaires sont dans Paramètres → OpenEVV. Le panneau suit la langue de la voix choisie à son ouverture.

Pauses et lecture

Raccourcir toutes les pauses est activé initialement. Choisissez les pauses normales, le raccourcissement final ou toutes les pauses. Les pauses explicites de NVDA ont un pourcentage distinct. Autres options : prédiction de phrases, chiffres/paires/triplets, codes de vérification, cinq modes d’épellation, majuscules, nettoyage, SSML et sept options de lecture de code.

Audio et fichiers

64 combinaisons langue/voix, huit fréquences, cinq modes de rééchantillonnage, correction de niveau et égaliseur cinq bandes. Balance gauche/centre/droite. Testez les réglages enregistrés ou exportez un WAV stéréo PCM16. Appliquez les modifications avant le test. Jusqu’à 100 000 caractères, moteur isolé et annulation sans écraser le fichier cible.

Intégration NVDA

Configurez les dictionnaires, abréviations personnelles, symboles et descriptions CLDR des emojis dans NVDA. Le code et les nombres sont préparés avant les symboles. L’épellation des caractères demandée par NVDA n’est pas doublée. Bruit blanc et maintien audio utilisent les réglages globaux NVDA, jusqu’à 300 secondes. Ils n’empêchent pas la veille de Windows et ne garantissent pas une latence nulle.

Compatibilité et validation

Prévu pour NVDA 2026.3 x64 ; manifeste 2026.1–2026.3. DLL réelle, 64 voix, rééchantillonnage, pauses et WAV testés. API et panneau vérifiés avec les sources officielles et des simulations. Non testé dans une session réelle NVDA 2026.3. Le mode classique rééchantillonne depuis 11 025 Hz. Qualité propose Large bande et Base native de 16 kHz, expérimentaux. Le mode natif sélectionne une sortie de 16 kHz ; les sorties supérieures sont rééchantillonnées depuis cette base. Rétablir les valeurs par défaut revient au mode classique sans modifier voix ou égaliseur. Ces modes sont enregistrés par profil et appliqués aux exports WAV. Choisissez un autre synthétiseur ou réinstallez la version précédente pour revenir en arrière. Pas de mise à jour automatique.
